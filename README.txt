FUTURE MARKETS TECHNOLOGY - WEBSITE FILES

HOW TO GO LIVE (Hostinger / cPanel / any web host)
1. Open your hosting File Manager for futuretechmarkets.com.
2. Open the folder "public_html".
3. Upload everything inside this zip (not the zip itself) into public_html.
4. Visit https://futuretechmarkets.com - the site is live.

FORMS (contact, brand sign-up, newsletter)
- Forms send to info@futuretechmarkets.com through FormSubmit (free).
- The FIRST time any form is submitted, FormSubmit emails info@futuretechmarkets.com
  an activation link. Click it once. After that, all submissions arrive by email.

AFTER LAUNCH (SEO)
1. Add the site to Google Search Console and Bing Webmaster Tools.
2. Submit https://futuretechmarkets.com/sitemap.xml in both.

TO REPLACE AN IMAGE
- Images load from Unsplash/Pexels for now. Send the new images to Claude and
  they will be swapped in and the files regenerated.
